Before you run it

  • Install the NVIDIA VFX SDK 1.3 features, or the nvidia-vfx wheel + Program Files 0.7.6 runtime.
  • Point NVVFX_LIB_DIR at the flat nvvfx\libs folder, or put it beside ffmpeg-nvvfx.exe.
  • For 8-bit → 10-bit, the builder adds scale_d3d11=format=p010 before nvvfx.
  • Artifact reduction is limited to 1920x1080.

Static command builder. NVIDIA runtime DLLs and models are not distributed here.
